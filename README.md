# Локальный архив Архивача

Небольшое Python-приложение для возобновляемого скачивания тредов `arhivach.vc`,
их хранения в SQLite и полнотекстового поиска по сообщениям. Оно намеренно
использует только стандартную библиотеку Python (3.11+).

## Сборка Windows EXE

На Windows установите PyInstaller в используемый Python (`py -m pip install
pyinstaller`), затем запустите `build_windows.bat` двойным щелчком или из
`cmd`. Готовый автономный файл появится по пути
`dist\\ArhivachArchive.exe`. Консольный режим оставлен включённым, чтобы были
видны сообщения crawler-а и ошибки сети.

## Быстрый старт

```bash
python -m arhivach_archive init --database data/archive.sqlite3
python -m arhivach_archive crawl --database data/archive.sqlite3 --tail-page 54367 --pages 10
python -m arhivach_archive serve --database data/archive.sqlite3
```

`crawl` начинает с хвоста индекса. Номер страницы не сохраняется как
прогресс: вместо этого фиксируется `pages_done_from_tail`. Перед каждым
запуском скрипт получает актуальный хвост (`--tail-page`); соответственно,
новые треды в начале списка не сдвигают уже пройденный архив. Идентификатор
треда является первичным ключом, а скачивание уже завершённых тредов не
повторяется. Для фонового catch-up запустите `crawl --mode head`: он идёт с
начала и останавливается после страницы, состоящей из ранее обработанных
тредов.

## Настройка медиа

По умолчанию медиафайлы не скачиваются. Создайте JSON-файл правил:

```json
[
  {"mode": "thumbnail", "tags": ["/g/", "Genshin Impact"]},
  {"mode": "full", "keywords": ["Genshin Impact"]},
  {"mode": "none"}
]
```

Правила применяются сверху вниз; первое подходящее определяет режим. Поля
`tags` и `keywords` необязательны, сравнение регистронезависимое. Передайте
файл как `--media-rules rules.json`; режимы: `none`, `thumbnail`, `full`.
Медиа сохраняются в `data/media/<thread_id>/` и никогда не влияют на FTS.

## Веб-интерфейс

После `serve` откройте <http://127.0.0.1:8080>. Поиск использует SQLite FTS5:
поддерживаются слова, фразы в кавычках, `AND`, `OR`, `NOT` и префикс `слово*`.
Страница треда показывает сохранённые посты и локальные изображения; разметка
сохранена простой и близкой к исходному виду Архивача.

## Бережное скачивание

По умолчанию пауза между запросами составляет 1 секунду, а ответы 429/5xx
повторяются с экспоненциальной задержкой. Не запускайте несколько crawler-ов
на одной БД: SQLite защищает данные транзакциями, но не ограничивает нагрузку
на удалённый сайт.
